# Исправление сообщения об обрыве загрузки PDF

Статус: выложено на https://zaryaproekt.ru/ 26.09.2026.
Снимок подготовлен 22.09; его имя сохранено для воспроизводимости.

## Причина и исправление

В журнале production загрузка `/studio/api/files` завершалась HTTP 200.
Следующий `/studio/api/calculate` падал с ValueError: для жилой ветви
таблицы 7.1 не задана длина общего коридора. Клиент сначала разбирал
любой ответ как JSON и ошибочно называл исключение разбора «обрывом связи».

- Studio спрашивает длину коридора только когда существующий нормативный
  resolver требует уточнения. Нет подстановки длины или условных двух струй.
- Расчёт расходов и документы сохраняются; проект остаётся `needs_inputs`.
- Ответ передаётся в тот же расчёт В2 и сохраняется через YAML/полный редактор.
  Фиктивные помещения и геометрия пожарного покрытия не создаются.
- Domain ValueError построения проекта возвращается как блокирующая причина,
  не откатывая успешно вычисленные расходы. Неожиданные ошибки не объявляются
  успешным расчётом.
- HTTP 500/502, 401, 413, конфликт версии, тайм-аут и ошибка отображения
  теперь различаются. Небезопасный автоматический повтор загрузки не добавлен.
- Версия `studio.js` повышена до 17, добавлен `studio_transport.js?v=1`.

Формулы, нормативная таблица, рабочий legacy и его архив не изменялись.
