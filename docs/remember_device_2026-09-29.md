# Сохранение входа на устройстве — 29.09.2026

По запросу пользователя вместо ежедневного ввода ключа добавлена включённая
галочка «Запомнить на этом устройстве на 30 дней».

- Запомненный сеанс: максимум 30 суток от входа, без 12-часового idle-таймера.
  Активность не продлевает этот предел. Cookie persistent, HttpOnly, Secure на
  HTTPS, SameSite=Strict; её срок ограничен сроком сеанса и ключа.
- Без галочки: обычный сеанс с пределами 12 часов бездействия / 7 суток;
  cookie без Max-Age/Expires. Браузер может восстанавливать такие cookie при
  восстановлении вкладок, поэтому выход кнопкой остаётся важен.
- Истечение/отзыв/перевыпуск ключа закрывают доступ; «Выйти» удаляет именно
  текущую сессию. Ключ в localStorage, URL или открытый текст базы не записывается.
- Старые сеансы не продлеваются и истёкшие не оживают. Для нового режима нужен
  один повторный вход с галочкой; текущие сеансы при выкладке не удаляются.
- API `remember_device` — strict bool, по умолчанию true. Старые клиенты с одним
  полем `key` при новом входе получают тот же новый режим.

Миграция аддитивная: отдельная таблица `remembered_sessions` по хешу токена и
триггер очистки после DELETE sessions. Старые четыре колонки `sessions` сохранены,
старый INSERT при откате совместим. Отсутствие отметки означает прежний короткий
сеанс. Очистка при входе не удаляет запомненные сеансы за простой более 12 часов.

Проверки: 300 regression-тестов; отдельные случаи 1/8/29/30 суток, предел ключа,
отзыв, logout, повторный вход/смена токена, короткий режим, перезапуск хранилища,
неизменность старых сеансов и миграция старой SQLite. Chromium: 320/390/1440px,
реальные persistent/session cookie и отсутствие ошибок JS; снимки без секретов
в `output/remember-device-qa`. Изолированный Docker-smoke подтвердил HTTP-вход,
проверки сроков и немедленный отзыв. Расчётное ядро и генераторы не затронуты.
