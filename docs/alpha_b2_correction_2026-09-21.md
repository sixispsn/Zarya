## Что изменилось

В legacy было 342 пары с окончанием NP=63. При NP>=63 включалась формула
`1.72 * NP**0.49 - 0.5`, противоречащая даже последней паре собственного массива.
Теперь 581 опубликованная пара, вплоть до NP=2000. Исправлена 41 неточная ячейка
старой таблицы, добавлены 239 отсутствовавших пар.

- NP<0.015: α=0.200; NP=0.015: α=0.202.
- На точном узле возвращается именно ячейка, включая NP=2000 → 426.80.
- Между узлами сохранена прежняя линейная интерполяция.
- NP>2000: явная ошибка с требованием обоснования; произвольной экстраполяции нет.
- NaN/±Inf отклоняются. Прежняя защита NP<=0 → 0.200 сохранена.
- А.2, calcBlock, суточные нормы, коэффициент 0.6, округление и тепловые формулы
  не изменялись. Зависимые часовые расходы и тепловая нагрузка могут измениться
  из-за исправленных α — это ожидаемое следствие, а не отдельная смена методики.

Строки сохранены в `tests/fixtures/sp30_b2_official.json` с номером страницы.
В PDF есть невидимый мусор в текстовом слое последней страницы: он исключён
после визуальной сверки. Первая строка «Менее 0,015» разобрана отдельно.
Разрывы сетки NP и неравномерности опубликованных значений не «сглаживались».
Текстовый экспорт пользовательского DOCX не использовался как эталон Б.2:
в нём встречаются сдвиги столбцов.

## Защита от повторения

- Все 581 точка сверяются с зафиксированным эталоном; fingerprint защищает
  сам эталон от случайного изменения вместе с реализацией.
- Для каждого интервала проверены середина и монотонность около обеих границ.
- Отдельно проверяются NP=63, малая/верхняя границы, NaN/Inf и отказ API за 2000.
- Оригинальный JS остаётся исполняемым историческим эталоном с ошибкой.
  `scripts/legacy_demand_reference.mjs` по умолчанию не исправляет его.
  Только явный флаг `approved_l01_correction` подставляет исправленную Б.2;
  calcBlock исполняется из исходного HTML без замены.
- Формулы потоков проверяются против этого явно обозначенного JS-эталона
  для всех 29 категорий потребителей и смешанной группы.

Это исправление Б.2, а не завершённая нормативная аттестация всего расчётника.
Проверка: 1416 тестов в выбранном наборе прошли (Б.2, расходы, legacy parity,
дождевой расчёт, Studio, В1/Т3, водомеры, насосы, rules, К1 и учебный расчёт).
Ruff, проверка синтаксиса JS и git diff --check — без ошибок.
Локальный сервер 127.0.0.1:8766 перезапущен с прежними каталогами черновиков;
его API подтверждает новые числа и возвращает 400 при выходе за таблицу.
Условия выбора между Б.1 и Б.2 по N/P остаются отдельной задачей аудита.
Ранее сохранённые числовые результаты и PDF нужно пересчитать; автоматического
перезаписывания пользовательских проектов или выкладки на сервер не выполнялось.
