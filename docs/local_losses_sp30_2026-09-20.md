# Местные потери: согласованная нормативная корректировка

Основание: прямое указание пользователя 20.09.2026 «делаем как в СП» после
предъявления несогласованности коэффициентов. Пункт 8.28, формула (15)
СП 30.13330.2020: `H = i·l·(1+k_l)`.
Источник: https://api.faufcc.ru/api/assets/348e662a-c0ae-43ad-9ace-9c96309387b6,
печатная страница 30.

| Назначение сети | k_l |
| --- | --- |
| Хозяйственно-питьевая жилых и общественных зданий | 0,30 |
| Объединённая хозяйственно-противопожарная | 0,20 |
| Производственная | 0,20 |
| Объединённая производственно-противопожарная | 0,15 |
| Противопожарная | 0,10 |

Назначение сети не выводится только из назначения здания: производственное
здание может содержать хозяйственно-питьевую сеть. Производственные виды
задаются явно в `source_data.network_kind`.

## Что изменено

- Общий справочник для сводного расчёта напора и гидравлики В1.
- `network_kind` проходит через последовательные участки, дерево, увязку
  кольца, сценарии отказа и проверку вводов. Для вводов не существует
  отдельного безусловного коэффициента 0,10.
- Проценты применяются только к линейным потерям; готовые суммы с местными
  сопротивлениями остаются без повторного умножения.
- Противоречащие норме старые ручные коэффициенты дают явную ошибку.
  После ошибки актуальной гидравлики старые потери не попадают в насос/ПЗ.
- В ПЗ коэффициент 0,15 не округляется в подписи формулы до 0,2.

## Границы

`legacy/sp30_calculator.html` не изменён. В нём детальная гидравлика участков
отсутствует, а `ΣHl` является входом насосного расчёта. Это не перенос новой
формулы из HTML: нормативная корректировка существующего расширения явно
принята пользователем. Legacy-таблицы, расходы, насосная формула и округление
их результатов сохранены.

Детальная модель В2 с заданными эквивалентными длинами местных сопротивлений
не получает дополнительную процентную надбавку: две методики не складываются.
Изменение этой отдельной модели и её исходных данных не маскируется заменой
коэффициента в модуле В1.

Состав ПЗ ИОС2 сохранён: ГОСТ Р 21.619-2023, 5.1.8 (напоры и насосы),
5.1.21 и приложение А, форма 2 (баланс отдельным листом). Схемы и ИОС3
данной правкой не меняются. При отсутствии длины, сечения, расхода или
шероховатости нет выдуманного значения потерь. Эта правка не заменяет
недостающий ввод геометрии/оборудования в Studio.

Проверка: `tests/test_water_local_losses.py`, существующие тесты гидравлики,
сводного напора, legacy parity, нормативной матрицы и интеграции ИОС2.
