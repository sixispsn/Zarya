# Объекты закрытого пилота — 28.09.2026

## Что сохраняется

В Studio появилась отдельная команда «Сохранить версию для пилота». Инженер выбирает новый объект с псевдонимом либо свой существующий объект, проверяет снимок, отдельно подтверждает передачу владельцу ЗАРИ. Согласие не отмечается автоматически. История доступна через «Объекты пилота».

Версия содержит стабильный ID объекта, автора, дату, номер, сборку, ревизию черновика, подтверждённые исходные, допущения/статусы, доступные результаты и SHA-256. Передаваемые текстовые пояснения показаны до согласия. Название исходного проекта заменяется явно введённым псевдонимом. Имена документов, PDF, цитаты, кандидаты распознавания и ссылки на личные документы не архивируются.

Результаты допускаются в снимок только при совпадении сборки и SHA-256 текущих принятых исходных с меткой пересчёта. Иначе сохраняются только исходные с требованием пересчёта. Расчётные формулы и генераторы документов не изменены.

## Хранение и доступ

- Таблицы `pilot_objects` / `pilot_versions` в существующем приватном `_pilot/access.sqlite3`, включая резервную копию общего тома.
- Версии неизменяемы через интерфейс; UPDATE дополнительно запрещён SQLite-триггером. Следующая итерация получает новый номер транзакционно.
- Читатели: автор и владелец-администратор. Добавляет версию только автор, не другой тестер и не администратор от его имени.
- При потере ответа повтор запроса возвращает квитанцию сохранения без дубля, включая повтор после обновления страницы с тем же намерением. Конфликт изменённого запроса не скрывается.
- До 100 объектов на участника, 1000 версий на объект, 20 новых сохранений в час; снимок до 1 МБ. Пагинация списка и истории.
- Рабочий черновик при сохранении не меняется. Удаление исходного PDF не удаляет отдельно переданный снимок — это явно написано до согласия. Автоматического копирования без команды нет. Запрос удаления сохранённых версий пока направляется владельцу.
- Согласие версии `pilot-snapshot-v1`, Origin/CSRF-проверки, персональные права, запрет кеширования, экранирование текста.

## Границы первого этапа

Продолжение 28.09.2026: отдельное прикрепление финальных PDF реализовано, см. [комплект после экспертизы](pilot_attachments_2026-09-28.md). Сам снимок по-прежнему хранит только исходные и числа; вложения требуют нового явного согласия.

Это архив исходных и чисел, **не** архив ПЗ/схем и **не** подтверждение экспертизы. Загрузка финального комплекта, разрешение на его использование, стадии прохождения экспертизы и сопоставление с исходной версией — следующий отдельный этап. Нормативные методики не «обучаются» автоматически на загруженных проектах.
