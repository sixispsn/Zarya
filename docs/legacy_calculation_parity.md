# Матрица соответствия расчётов legacy SP Calculator

Канонический источник: `legacy/sp30_calculator.html`. Статус «parity» означает совпадение исходных таблиц, формул, ветвлений, округления и контрольных числовых результатов.

Обновление 21.09.2026: по прямому указанию пользователя рабочий HTML теперь
содержит согласованные исправления. Неизменённый исторический источник перенесён
в `legacy/archive/sp30_calculator.pre-2026-09-21.html`; старые упоминания
«HTML неизменён» ниже и в отчётах относятся к архиву. Исторические оракулы читают
его, а `test_working_legacy.py` проверяет исправленный HTML напрямую, без overlays.
Сборка и границы: [legacy/README](../legacy/README.md).

Важно: parity не доказывает соответствия СП. Аудит водомеров 20.09.2026
обнаружил ошибку DN65 в самом legacy, неподтверждённую проверку минимального
расхода и отличие округления Python/JS. 21.09.2026 пользователь согласовал
эти три исправления; они внесены без изменения исходного HTML.
Каждая новая ошибка требует отдельного обсуждения; [подробности](water_meter_audit_2026-09-20.md).

Затем отдельно согласована L01: полная Б.2 без обрыва NP=63 и экстраполяции.
[Отчёт с контрольными числами](alpha_b2_correction_2026-09-21.md).

Затем отдельно согласована L02: исправлено разложение кривой системы,
убраны произвольные потери при отсутствии данных; [отчёт](pump_curve_correction_2026-09-21.md).

Отдельным продолжением согласована L03: строгий допуск по полной Q/H до

### Внешние подводы кольца В2 — 04.10.2026

По продолжению пользователя для контрольной секции 3.2 расширена топология
существующего сценарного решателя, а не формулы legacy: один/два источника
могут подключаться к кольцу последовательными подводами без ответвлений.
Сопротивление подвода равно сумме `A·Lэфф`; потери считаются по фактической
подаче этого ввода и участвуют в двухконтурной увязке. При отказе одного ввода
оставшийся несёт полный расчётный расход. `Hгар` и отметка источника остаются
в наружной точке подключения. Подводы включаются в таблицу участков.

Для двух источников сводное `Hтреб = Hгар1 − margin` — эквивалент при одинаковой
добавке к обоим источникам, не готовая рабочая точка одной насосной. Без схемы
подключения насосной автоматический подбор В2 не производится. Неподдержанный
двухвводный случай больше не превращается молча в одновводный.

Границы: одно кольцо, независимые подводы к разным узлам, заданные отборы на
тупиковых ветвях. Отборы/разветвления до кольца, общий участок двух подводов и
многокольцевая топология требуют отдельного расширения. Это не динамическая
и не pressure-driven модель: при дефиците результат показывает недостижимость
заданного расхода, а не фактическую подачу городской сети.

Контроль: `tests/test_ring_external_inlets.py` (аналитическая симметричная сеть,
асимметрия, пьезометрия, обратные клапаны, последовательные подводы, оба отказа,
явный отказ на неподдержанных данных), прежние `test_ring_hydraulics.py`,
`test_samara_section_study.py`. Нулевые сопротивления подводов воспроизводят
старую постановку с источниками на кольце. HTML и нормативные таблицы этим
расширением не изменены. В учебном примере местные потери 10% линейных,
согласованные ранее, заданы один раз как `Lэкв = L·local_loss_factor('fire')`;
дополнительной надбавки поверх `Lэфф` нет.

## Контрольный golden подбора В1

Для `Hgeom=25 м`, `ΣHl=5 м`, `Hпр=20 м`, `Hгар=20 м`, `Q=5 м³/ч`, одного повысительного насоса и `NPSHa=8 м` функции legacy дают:

- `Hp = 30 м`;
- `Hстат = 20 м`;
- `k = 0,4 м/(м³/ч)²`;
- принятый насос Grundfos CR 10-4;
- рабочая точка `Q=5,94 м³/ч`, `H=34,1 м`;
- итоговый score `160`.

Это исторический результат до согласования L02. После исправления для тех же
данных H0=25 м, k=0,2; предварительный кандидат CR 10-4, Q=6,38 м³/ч,
H=33,0 м, score=150. Новый результат сопоставлен с исходным JS при явно
включённой поправке L02. Это историческое состояние до L04.

После L04: Q=6,361998256 м³/ч, H=33,095004361 м, score=150.
Невязка Hнас(Q)−Hсист(Q) не более 1e-9 м; в таблице выводится 6,36 / 33,1.
Кривая сети остаётся оценочной; точное численное пересечение не заменяет
проверку регулирования, кавитации и актуальности каталожной характеристики.
