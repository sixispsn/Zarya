# Самара: единая выдача ИОС2 + ИОС3 — 05.10.2026

## Результат на сайте

`https://zaryaproekt.ru/studio` → «Попробовать на примере» → «Самара · 16 этажей».
Это фиксированный контрольный пример, а не перенос его допущений на любые здания.

- 16 вариантов PDF, включая общий файл из 52 страниц: 40 ИОС2 + 12 ИОС3.
- Сохранены вложенные закладки двух разделов и отдельных приложений.
- ИОС3: ПЗ, расчёты К1/К2, баланс, характерная принципиальная схема,
  её условные обозначения и предварительная спецификация.
- К1 4,785 л/с, К2 11,518 л/с, суточный баланс 63 м³/сут проверяются по
  одной модели. Расхождение сохранённых величин останавливает выдачу.
- Текст ограничений В2 больше не попадает в ПЗ канализации через общие
  примечания документа. При отсутствии подробной сети вместо пустых таблиц
  показываются ограничения расчёта, а не вымышленные результаты.
- УГО берутся по составу характерной схемы, а не только по пустому реестру
  точной сети; состав легенды не превращается в количество для спецификации.
- Насосный отчёт резервирует место под штамп. Блок вводного коллектора
  находится внутри рамки, подпись водонагревателя переносится внутри блока.
- Опубликована ранее проверенная корректировка В2: отверстие 21 мм только
  на 15-м этаже, 13–14 этажи по 19,5 мм. 13 824 ремонтных сочетания проходят
  в принятой модели; резервный насос не увеличивает расчётную подачу.

`can_release=False`: это не готовый комплект для экспертизы. Полные планы,
реальная топология и количества, расстановка/покрытие ПК, паспортные данные
и ранее перечисленные ограничения не подтверждены автоматически.
Точные расходы ветвей и количества труб из характерного разреза не выводятся.
