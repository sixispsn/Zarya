# Справочное место строительства — 29.09.2026

В первом окне «Здание» добавлен необязательный компактный пункт «Место
строительства». Отдельное окно: адресный поиск, выбор/перемещение метки,
ручные координаты WGS 84 и необязательный запрос справочной высоты.
Место сохраняется отдельно для каждого личного проекта, без обязательных лампочек.

## Граница с расчётами

`site_location` — метаданные Studio, **не** `answers` и не расчётный параметр.
Ничего автоматически не переносится в Hгеом, Hгар, подвал, выпуск, ±0,000,
геологию, сейсмику, вечную мерзлоту или город расчёта дождя. Расчёты, ПЗ,
схемы, спецификации, legacy и ранее созданные PDF не изменяются/не отзываются.
В схему данных выпуска и снимки расчётных параметров пилота место не включается.

Высота SRTM — приближённое справочное значение, сетка около 30 м, **не**
инженерная топосъёмка и не привязка к принятой на объекте системе высот.
Для широт вне ±60° либо пробелов покрытия возвращается «нет данных», не ноль.
Недоступность внешнего сервиса не мешает сохранить точку и продолжить расчёт.
Москва при первом открытии — только начальный вид карты: метка не задана.

## Провайдеры и приватность

- Подложка: [OpenStreetMap](https://operations.osmfoundation.org/policies/tiles/).
  Только видимая область после нажатия «Показать карту», без предварительного
  скачивания/офлайн-архива. Видимая атрибуция, стандартный HTTP-кеш браузера,
  у изображений `referrerPolicy: origin` — передаётся только домен, без путей
  проектов. Общий `no-referrer` для остальных страниц не меняется.
- Адресный поиск: [Photon](https://github.com/komoot/photon#demo-server),
  данные OSM. Явная кнопка, без автопоиска при наборе, без reverse-geocoding.
  Сервис разрешает разумную нагрузку, но не гарантирует доступность.
  Публичный Nominatim API не используется.
- Высота: [Open Topo Data](https://www.opentopodata.org/#public-api),
  [SRTM30m v3](https://www.opentopodata.org/datasets/srtm/).
  Только по отдельной галочке после раскрытия уведомления о внешних сервисах.
  Ограничения публичного API: 1 запрос/с и 1000/сутки.
- Серверный кеш: адресные результаты 7 суток, высоты 90 суток. Ключи запросов
  хешируются, авторы/проекты в кеш не попадают. Файл SQLite закрыт правами 0600.
  Общий для процессов лимит каждого сервиса: не чаще 1 запроса/1,1 с и не более
  500/сутки, максимум 2000 записей кеша, тайм-аут 8 с, ответ до 128 КиБ.
- До включения карты нет запросов к внешним сервисам. Перед включением
  описана передача IP/области просмотра, адреса и координат; PDF, ключи,
  расчётные данные не передаются. Для конфиденциальных объектов — ручной ввод
  без запроса высоты. Место не определяется по IP или геолокации устройства.

Leaflet 1.9.4 хранится локально с BSD-2-Clause лицензией. SHA-256 JS
`db49d009c841f5ca34a888c96511ae936fd9f5533e90d8b2c4d57596f4e5641a`, CSS
`a7837102824184820dfa198d1ebcd109ff6d0ff9a2672a074b9a1b4d147d04c6`.
Хеши соответствуют SRI [официальной страницы](https://leafletjs.com/download.html).

## Настройки и эксплуатация

`ZARYA_GEO_ENABLED=0` отключает онлайн-сервисы, ручное сохранение остаётся.
`ZARYA_GEO_DIR` — каталог общего кеша (по умолчанию `_geography` под Studio).
`ZARYA_MAP_TILES_URL`, `ZARYA_MAP_ATTRIBUTION`, `ZARYA_MAP_ATTRIBUTION_URL`,
`ZARYA_MAP_PROVIDER_LABEL` задают подложку; `ZARYA_GEOCODER_URL` — Photon-
совместимый API; `ZARYA_ELEVATION_URL` — совместимый endpoint SRTM30m.
При смене поставщика необходимо пересмотреть уведомление пользователю,
атрибуцию, лицензию, квоты и состав данных; платная подписка автоматически
не подключается. Для роста пилота — собственный/договорной сервис, не
снятие лимитов общественных серверов.

Сохранение защищено персональным входом, проверкой Origin, активного проекта,
revision и повторной проверкой после внешнего запроса. Геолокация никогда не
сохраняется в другой открытый проект. Старые черновики совместимы, миграции нет.

Проверки: `tests/test_studio_location.py`, `scripts/verify_location_ui.cjs`,
`scripts/verify_location_container.py` + общий набор Studio/пилота/legacy.
Браузерные тесты используют искусственные тайлы и ответы поиска, не скачивают
подложку публичного сервера. Снимки интерфейса: `output/site-location-qa`.
