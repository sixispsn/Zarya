# Самара: конечный горизонтальный участок К1

Статус: проверенный учебный вариант, не утверждение о готовности всей сети
или комплекта к экспертизе. Отдельное продолжение согласованной проверки
формулы (7) и интерполяции Ks. В1/В2/Т3/Т4, К2 и legacy не меняются.

## Исходные и граница

Встроенный пример получает отдельный открытый набор исходных
`demo/samara_k1_review_assumptions.json`. Он привязан к прежнему подписанному
снимку Самары; пожарная матрица не пересчитывается и не переписывается.
Видимые ответы Studio, Request/YAML, модель, расчёт, ПЗ и схема используют
один `SectionMainInput`. Никаких ручных исправлений готового Project/PDF.

- N = 143 мойки + 143 ванны + 175 унитазов + 175 умывальников = **636**.
  Это укрупнённый учебный состав: 143 квартиры по четырём приборам, плюс
  два дополнительных санузла (унитаз и умывальник) на каждом из 16 этажей.
  Не 350 жителей, не число символов на разрезе, не результат OCR.
  Машины и нежилые потребители в этот вариант не включены. Полный состав
  и подключение приборов перед реальным выпуском требуют подтверждения.
- **L = 10 м** от последнего присоединённого стояка до ближайшего колодца,
  без новых присоединений. Разрешённое учебное допущение, не обмерная длина
  всего коллектора. Весь расход изолированной секции условно собран перед
  проверяемым конечным участком; на каждый стояк он не переносится.
- qч = **7,710 м³/ч**, q0s = **1,600 л/с** из текущего общего расчёта.
- PP Ostendorf HT/HTEM **110×2,7 мм**, dвн = **104,6 мм**.
  Геометрия из существующего проверенного каталога `sewer_pipe_catalog.py`;
  наружные 110 мм не подменяются условным DN100.
- n = **0,011** — явно заданный учебный коэффициент, не паспортное
  значение производителя. Уклон **0,010 м/м = 10‰**, проверен расчётом;
  правило 1/d автоматически не применялось.

## Расчёт и выбор сечения

Опорные ячейки: N=500/L=10 → Ks=0,86; N=1000/L=10 → Ks=0,96.
Согласованная линейная интерполяция по N даёт **Ks=0,8872**.

q_sL = 7,71/3,6 + 0,8872×1,6 = **3,5611866667 л/с**.
В выдаче **3,561 л/с**; значение до округления передаётся решателю.
Справочный результат формулы (5), **4,785 л/с**, сохранён отдельно
и не используется для этого горизонтального участка.

| Проверка при i=0,010 | Прежний условный DN150, PP 160×3,9 | Принятый учебный DN100, PP 110×2,7 |
|---|---:|---:|
| dвн, мм | 152,2 | 104,6 |
| V, м/с | 0,792 | 0,808 |
| h/d | 0,2956 | 0,5102 |
| V√(h/d) | 0,430 | 0,577 |
| Самоочищение / минимум наполнения | Не выполнены | Выполнены |

Диаметр не увеличивается ради старого секундного расхода и не выбирается
автоматически генератором по этому одному примеру. Проверены конкретные
входные варианты существующим решателем Шези-Маннинга. Переход на DN100
касается учебного характерного участка, не массовой переделки исходного
проекта или расчёта всех ветвей.

L таблицы 5.1 не переносится в спецификацию как длина всей магистрали.
В СО передаются материал и размеры выбранной трубы, количество остаётся
незаданным до ведомости объёмов. Отметка лотка выпуска −2,40 м сохранена.
Начальная отметка коллектора, реальные колодцы, обслуживание и подпор
этой гидравлической проверкой не подтверждаются.

## Защита от устаревшего результата

В документный снимок входят и прежний базовый хеш, и полный набор новых
допущений. Изменение N/L, состава, материала либо версии требует открыть
пример заново; старый просмотр не подтверждает новый расчёт. Для обычных
объектов эти значения не становятся значениями по умолчанию.

ПЗ и расчётный лист показывают основание N/L, метод Ks, опорные ячейки,
трубу, n и результаты. На принципиальной схеме выводятся тот же DN/i и
Q/V/h/d. Проверка состава/оформления ведётся в границах ГОСТ Р 21.620-2023,
пп. 5.1.3.3, 5.1.4.1, 5.2.2: баланс остаётся отдельным листом в рамке;
планы и неподтверждённые привязки не объявляются выполненными.

Регрессия: `tests/test_samara_k1_review.py`; сквозная выдача через обычный
HTTP Studio: `scripts/check_samara_document_consistency.py --output-dir
output/pdf/samara-k1-reviewed`. Полный комплект остаётся предварительным,
выпуск не разрешён. Изменения локальные; публикация отдельным шагом.
