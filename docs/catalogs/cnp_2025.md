## Перенесённые серии

- PFFS CDM10-2/3/4/5/6/7/8/9/11/15 и
  CDM15-1/2/3/4/5/7/9/11: состав и мощность установки — страницы 38-39
  каталога PFFS.
- PBS CDM10-3/4/6/8/10/13/15 и CDM15-2/3/5/7/9/11: состав и мощность
  установки — страницы 46-47 каталога PBS; стандартная комплектация PN16 и
  температурное исполнение до +70 °C — страницы 6-7.
- Базовые CDM10: точные табличные Q-H — страница 27 каталога CDM/CDMF;
  Q-NPSHr — страница 26.
- Базовые CDM15: точные табличные Q-H — страница 29 каталога CDM/CDMF;
  Q-NPSHr — страница 28.
- TD32-10(I)/2: табличная Q-H характеристика, мощность и график NPSH —
  страницы 74-75.

Для PFFS и PBS использована кривая с индексом `1`: она относится к одному
рабочему насосу. Кривые с индексами `2...6` показывают параллельную работу и
не переносятся как характеристики одного агрегата. Для В2 резервный насос не
суммируется с рабочим.

Первичная оцифровка Q-H из каталогов установок заменена точными строками таблиц
CDM/CDMF. Кривые NPSH извлечены из векторных путей PDF, пересчитаны по
координатным осям графиков и округлены до 0,1 м. Контрольные точки:

| Серия | Q, м³/ч | NPSHr, м |
|---|---|---|
| CDM10 | 0 / 5 / 6 / 8 / 10 / 12 / 14 | 1,0 / 1,3 / 1,4 / 1,7 / 2,0 / 2,3 / 2,8 |
| CDM15 | 0 / 8 / 10 / 12 / 14 / 15 / 16 / 18 / 20 / 22 / 24 | 1,3 / 1,5 / 1,5 / 1,6 / 1,7 / 1,8 / 1,9 / 2,0 / 2,3 / 2,7 / 3,4 |

В расчёте NPSHr интерполируется по расходу одного рабочего агрегата. При двух
параллельных насосах для NPSH используется половина суммарного расхода; при
последовательной схеме — полный расход через каждый насос. Проверка выполняется
по условию `NPSHa >= NPSHr + 0,5 м`, указанному изготовителем на странице 18.
Поле постоянного NPSHr у таких моделей остаётся `None`, поскольку вместо
условного числа хранится полноценная Q-NPSHr характеристика.

Первый буклет используется только для подтверждения связи брендов CNP и Aikon.
Второй относится к консольным насосам и числовых данных для CDM/PBS/PFFS не
добавляет; характеристики из буклетов в расчёт не переносились.
