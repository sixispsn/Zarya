# Единый вход Studio и стабильная главная

Статус: выложено на https://zaryaproekt.ru/ 26.09.2026.

## Причина

Клиент считал наличие сохранённого черновика командой открыть форму. После клика
по логотипу HTML сначала показывал главную, затем GET `/studio/api/draft` скрывал
её. Ссылки общей шапки и кнопки handoff дополнительно уводили в прежний редактор,
сохраняя отдельную YAML-копию, а не продолжая текущий черновик.

## Новый контракт

- `/studio` (и `/` через редирект) — главная даже при существующем черновике.
- `/studio?view=project` — явно открыть тот же текущий проект; при отсутствии
  черновика показать старт. Форма не мелькает во время загрузки главной.
- «Продолжить» открывает проект без копирования, создания новой ревизии и расчёта.
- Введённые значения сохраняются перед обычным переходом по логотипу/навигации.
  При ошибке сохранения переход не выполняется.
- «Мои проекты» ведёт на новую страницу `/studio/projects`. Она показывает только
  текущий браузерный черновик и свёрнутый, явно обозначенный архив прежних YAML.
- Архив не мигрируется автоматически: можно скачать оригинальный YAML или явно
  открыть прежний редактор в отдельной вкладке. Поля старых проектов не отбрасываются.
- В основной шапке нет редактора, измерителя, модели здания и переходов handoff.
  Ручные параметры остаются внутри Studio. Нормативная база — отдельная справка.
- Серверный handoff остаётся совместимым со старыми клиентами, но новый UI его
  не вызывает. Сами прежние генераторы/ядро не удаляются.

## Границы этапа

Это первый шаг согласованного единого алгоритма, не заявление о завершённой
миграции всех инженерных настроек. Сохраняется один текущий черновик браузера;
межпользовательский список и учётные записи не добавлены. Старый архив по-прежнему
за общим паролем сайта — это не персональное хранилище разных клиентов.
Учебные ветви и полная модель сети требуют дальнейшей унификации. Недоступные
данные не заменяются догадками, проверки выпуска и формулы не ослаблены.

## Проверки

`tests/test_studio_navigation.py` и исполняемый `tests/studio_navigation.test.cjs`:
восстановление обычного/учебного черновика не открывает форму на главной;
навигация не меняет ревизию; черновик другого браузера не показывается;
архив выгружается побайтово без изменений; основной UI не вызывает handoff.

В браузере: ввод 20 жителей / 2 этажа / 8 квартир → логотип → перезагрузка
главной → «Продолжить» → все три числа сохранены → новая страница проектов.
Изолированное хранилище, реальные пользовательские проекты не использовались.
