# Рабочий расчётник и неизменённый архив

- `sp30_calculator.html` — автономная рабочая копия, обновлена 15.10.2026
  по прямому указанию пользователя. Открывается в браузере без сервера.
- `archive/sp30_calculator.pre-2026-09-21.html` — исторический оригинал,
  **не использовать как исправленную версию** и не редактировать.
- `approved_functions.js` — исходники согласованных функций для сборки;
  рабочий HTML содержит их внутри и не зависит от внешнего JS-файла при открытии.

SHA-256 архива:
`ace54b14e2f30fadaec768ec06aa5a326553709b9a869263208ef8ee58df3788`.

В рабочий файл перенесены:

1. L01: проверенная Б.2 (581 пара), без провала при NP=63 и экстраполяции.
2. L02: оценочная кривая системы согласована с расчётным напором;
   незаданные потери не заменяются 5 м или произвольным коэффициентом.
3. L03: кандидат обязан обеспечить расчётную пару Q/H до рейтинга.
4. L04: конечная точка сохранена; рабочая точка — единственное действительное
   пересечение, не минимум невязки. График использует ту же кривую системы.
5. L05: превышение каталога водомеров не заменяется максимальным DN.
6. DN65: S=0,0081; минимум проверяется по отдельно введённому паспорту и
   минимальному расчётному расходу, не по часовому максимуму. Без этих сведений
   результат — кандидат, не подтверждённый прибор.
7. L07 (06.10.2026): режим чистой циркуляции отделён от повысительного.
   Отдельные пустые поля Q/H и основание расчёта кольца; Hgeom/Hпр/Hгар не
   участвуют. Только каталожная проверка заданной пары, без фиктивной кривой
   системы или пересечения. Неподтверждённые материалы насоса не становятся
   пригодными для питьевой ГВС автоматически. См. `docs/hws_circulation_2026-10-06.md`.
8. L08 (15.10.2026): удалены начальные/скрытые 8 м NPSHa. Пустое поле -
   незавершённая проверка, ноль сохраняется. Отдельный баланс CNP с явными
   исходными доступен в раскрываемом блоке, без молчаливого переноса в подбор.
   См. `docs/pump_suction_2026-10-15.md`; форма - `npsha_inputs.html`.

`circulation_inputs.html` — исходник полей L07 для воспроизводимой сборки.
L06 — отдельное расширение Python для В2; в рабочий HTML не переносилось.

Дополнительно устранены два технических сбоя HTML без изменения формул:
`log` объявлен до использования при коэффициенте 0,6; повторный расчёт изоляции
не читает карточки результатов как строки ввода с отсутствующими полями.
При выходе Б.2 за предел результаты скрываются с объяснением; отказ водомера
не оставляет прежнюю принятую карточку.

## Воспроизведение и контроль

```sh
venv/bin/python scripts/rebuild_working_legacy.py
venv/bin/python scripts/rebuild_working_legacy.py --check
NODE_BINARY=/path/to/node venv/bin/python -m pytest -q tests/test_working_legacy.py
node scripts/verify_working_legacy.cjs
NODE_BINARY=/path/to/node venv/bin/python -m pytest -q tests/test_hws_circulation.py
```

Сборщик выполняет только зафиксированные преобразования и проверяет хеш архива.
Новый тест сравнивает рабочий HTML с Python без тестовых исправляющих overlays:
все ячейки Б.2 и середины интервалов, 720 сценариев водомеров, насосные режимы,
пересечения и отсутствие подбора. Браузерный тест использует Chrome/Playwright.

Исторические оракулы `legacy_demand_reference`, `legacy_meters_reference`,
`legacy_pumps_reference`, `audit_legacy_algorithms` по умолчанию читают архив.
Первые три умеют `working_copy=true` без overlays. Исполняемая проверка дождя
читает рабочий HTML: блок дождя байт-в-байт прежний; расход потребителей — с L01.
Разница 10,077/10,075 м³/ч для 500 жителей теперь устранена в рабочей версии;
исторический дефект по-прежнему воспроизводится архивными тестами.

## Ограничения

Это не объявление всех остальных ветвей полностью проверенными. В частности,
старый интерфейс В2 не заменяет актуальный нормативный слой приложения по СП 10.
Расширенный каталог насосов Python не скопирован в автономный HTML. Полная
трассировка Т3/Т4 и отдельная поучастковая методика приложения не являются
расчётами старого автономного файла. Учебные значения в его полях не заменяют ТУ.
Старые отчёты, в которых оригиналом назван прежний путь HTML, относятся к архиву.
